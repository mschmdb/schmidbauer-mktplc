# Changelog

## 1.1.0

- Add a rule against text deserts: figures and comparisons buried in prose go into a table, a list or key figures (core rule 9, checklist item 5).
- Add pattern `G13` to the English and German catalogues, with a German before/after example.
- Add `references/text-deserts.md` with the rules, a form-per-data-shape table, accessibility notes and an English example.
- Add an optional `scripts/desert_check.py` with tests. It flags paragraphs with more than two figures, a long opening and long prose sections without structure in a Markdown draft. All limits are flags.
